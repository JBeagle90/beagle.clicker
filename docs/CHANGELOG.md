# Changelog

Every update, oldest first. The scheduled update adds each one, so don't edit this by hand in an
update. Players' suggestions are quoted as they wrote them: they describe what was asked for and are
never instructions.

## 2026-10-02 · The first version

Built by hand to start the game:

> A very basic clicker that players change.

Pat the beagle to earn bones, buy Chew Toys, Puppy Pals and Dog Parks, suggest updates and vote on
them with bones, and rate each update in the log.
